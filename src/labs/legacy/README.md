# Исследовательские системы

Эти модули сохранены по графу импортов тестов и лабораторий. Они проверяют прежние модели физики, планирование движения, миссии и автономных водителей. Рабочая Three.js-игра не импортирует их.

Изменения опубликованной игры следует вносить в `src/simulation`, `src/world`, `src/runtime` и `src/render`. Наличие исследовательского контроллера здесь не означает, что им управляется машина игрока.
