# LOWTOWN v27: пешие маршруты и полёт

Проверка относится к исходнику `LOWTOWN` перед публикацией v27. Сцены сохранены вызовами реальных Canvas-функций проекта через `@napi-rs/canvas`; это не скриншоты live-браузера.

## Что изменено

- Самолёт не набирает высоту с места: для взлёта нужен разбег по размеченной полосе.
- Высота фиксированного крыла набирается пропорционально скорости; руль стал менее резким, обратный ход отключён.
- При заходе на посадку вне полосы самолёт держит текущую высоту и сохраняет управляемую тягу, чтобы пилот мог вернуться.
- Камера следит за корпусом самолёта, а не за наземной проекцией, и постепенно расширяет обзор на высоте.
- Разметка ВПП рисуется из тех же координат, которые использует физическая проверка посадки.
- Подсказки объясняют выход/посадку в транспорт и управление самолётом.

## Границы проверки

- Это аркадная изометрическая модель высоты, не полноценная аэродинамика: крен, тангаж, сваливание и ветер не моделируются.
- Автоматизированный браузер не может держать физическую клавишу газа в течение длительного времени через доступный UI-контроллер; последовательный манёвр самолёта проверен в детерминированных прогонах игрового кода, а браузер используется для проверки отрисованной сцены и приложения.
- Рендер-кадры показывают один уровень высоты и не доказывают визуальную читаемость во всех размерах экрана.
