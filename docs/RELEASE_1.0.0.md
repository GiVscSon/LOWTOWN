# LOWTOWN 1.0.0

Финальная браузерная сборка: https://givscson.github.io/LOWTOWN/.

Three.js, островной город с дорогами и 24 автомобильными мостами, ночное освещение, мокрый асфальт, подробные машины и фасады. Три положения камеры, меню паузы, сохранение прогресса и настроек, установка PWA и запуск без сети после первой загрузки.

В этом релизе берег открыт для плавания. При входе в воду появляются всплеск, круги и плавательные движения; можно вернуться на берег. После длительного плавания расходуется здоровье, спасение возвращает на сушу. Автомобиль тонет и эвакуируется. На трёх больших пляжах гуляют ещё 30 жителей, шестеро заходят плавать. Физические перила повторяют видимые кривые мостов и удерживают персонажа даже во время прыжка. У въездов, служебных дорог и соединений с пешеходными настилами оставлены согласованные видимые и физические проёмы.

Персонажи получили отдельные материалы кожи, волос и одежды, подробные руки, лица и обувь. Гидранты, скамейки, урны, телефоны, клумбы, стойки, почтовые ящики и пляжные зонты используют общие подробные модели. Небольшие отдельные предметы подвижны: удары и столкновения передают импульс, повреждают и разрушают их. Здания, крупные клумбы и несущая инфраструктура остаются закреплёнными.

Оружие: кулаки, бита, пистолет, дробовик и сигнальный пистолет. Попадания учитывают преграды, повреждают кузов и предметы, вызывают реакцию людей. Сигнальная ракета может зажечь объект; свидетели сообщают о происшествии существующей системе экстренных служб. Некоторые вооружённые жители отвечают при нападении. Магазины конечные; запас патронов для перезарядки не ограничен.

Действия сопровождаются анимацией: ожидание, ходьба и бег, прыжок и приземление, гребки и удержание на воде, удары, отдача, перезарядка, падение и подъём, посадка и выход. У жителей есть жесты разговора, чтения, кофе и телефона. Подробная таблица — docs/ANIMATIONS.md в исходниках. Движения и мировые эффекты останавливаются на паузе.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение / плавание | WASD, стрелки |
| Прыжок / усиленный гребок / ручной тормоз | Пробел |
| Удар / выстрел | F |
| Выбор оружия пешком | Q, 1–5 |
| Перезарядка | T |
| Войти / выйти из транспорта | E |
| Бег пешком / ускорение транспорта | Shift |
| Меню паузы | Esc |
| Карта / гараж / радио | M / G / R |
| Камера, погода, настройки | Кнопки интерфейса |

На телефоне доступны экранные кнопки, включая оружие и перезарядку. Q в воздушном транспорте сохраняет функцию взлёта/снижения.

## Архивы и запуск

`LOWTOWN-1.0.0-game.zip` — готовая статическая игра с `start.py` и `START.bat`. Распакуйте и запустите `python3 start.py` (Windows: Python 3 и `START.bat`). Откроется http://127.0.0.1:8080/. Не открывайте index.html как file://: модулям и PWA нужен HTTP. Сервер слушает только локальный адрес; остановка — Ctrl+C.

`LOWTOWN-1.0.0-source.zip` — исходники проверенного коммита, lockfile, документация и тесты. Нужен Node.js 20.19+ или 22.12+: `npm ci`, `npm run dev`. Production: `npm run build`, `npm run preview`. Упаковка: `npm run package:release -- --output /путь/к/архивам`; перед ней нужна production-сборка. SHA256, коммит, дерево и модуль сборки записываются в release-manifest.json рядом с архивами.

## Проверка и пределы

Матрица проверяет 30/60/120 Гц, вход/выход из воды, NPC, паузу, реальные края всех мостов, оружие, преграды, повреждения, перезарядку и движение уличных предметов. Браузерная проверка использует клавиши и сенсорные кнопки на desktop/mobile. Сохраняются проверки транспорта, погодных режимов, разрешений, экстренных служб и PWA.

Физика контактов использует ориентированные плоские тела с высотой прыжка; это не универсальная симуляция трёхмерных твёрдых тел. Изменения предметов и происшествия действуют в текущей сессии, сохранение содержит основной прогресс. Производительность программного WebGL в тестовой среде не является измерением FPS на вашем устройстве. Подробную графику можно облегчить через разрешение, тени, отражения, дальность и эффекты без изменения механик.

Ресурсы и источники: ASSET_SOURCES.md. Архив исходников не содержит node_modules, временные отчёты, окружение или секреты.
