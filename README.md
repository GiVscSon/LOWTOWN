# LOWTOWN

Браузерная игра о ночном городе: органическая сеть дорог, острова и мосты, пешеходы, дорожное движение, полиция и экстренные службы. Основной рендерер — Three.js; игра устанавливается как PWA и работает после загрузки без сети.

[Открыть игру](https://givscson.github.io/LOWTOWN/)

Версия **1.1.0**: восемь типов взрослых прохожих, подробные лица с морганием и экипировка, оружие и последствия происшествий, слышимое радио и звуковые эффекты, смена дня, ночи и погоды, сцепление шин, приоритет проезда, тактика полиции и настраиваемые мокрые отражения. [Управление, архивы и пределы релиза](docs/RELEASE_1.1.0.md). [Промпт для локальной Qwen](docs/QWEN_LOCAL_PROMPT.md).

## Запуск

```sh
npm ci
npm run dev
```

Для production-сборки: `npm run build`, затем `npm run preview`.

## Управление

WASD / стрелки — движение; пробел — прыжок пешком или ручной тормоз в машине; F — удар/выстрел пешком; Q или 1–5 — оружие, T — перезарядка; Shift — ускорение. E — выйти или сесть в транспорт, Q в воздушном транспорте — взлёт/снижение, M — карта, G — гараж, R — радио. Esc открывает меню паузы. На телефоне доступны экранные кнопки.

Меню содержит три положения камеры, разрешение, частоту кадров, дальность, освещение, отражения, тени, дождь и звук. Настройки сохраняются отдельно от прогресса. Полный режим доступен без автоматического снижения разрешения.

Мокрые улицы используют неоднородные материалы и прерывистые отражения света. У фасадов есть мощёные площадки, витрины и неон; на дорогах — люки и стоки. Кнопка погоды в HUD позволяет включить дождь и увидеть отражения и работающие дворники.

Машины имеют плавное освещение кузова, лак, хром и отражения ночного окружения; за тонированными окнами видны детали салона. У домов добавлены карнизы, балконы, пожарные лестницы и вентиляция крыш. Деревья, гидранты и контейнеры используют общие подробные модели. [Описание графического обновления](docs/VISUAL_POLISH_2026-10-04.md).

Прыжки, удары и подвижные предметы имеют физические последствия и анимации. Город дополнен ящиками, бочками, клумбами, почтовыми ящиками и велосипедными стойками; видны частицы контактов, струи гидрантов и пар. Интенсивность эффектов выбирается в меню. [Описание обновления и проверок](docs/INTERACTION_WORLD_2026-10-04.md).

## Структура

| Каталог | Назначение |
| --- | --- |
| `src/main.js` | Короткий вход: создаёт и запускает игровой runtime |
| `src/app/` | Запуск, ввод, звук, сохранения, PWA и телеметрия |
| `src/runtime/` | Единое состояние, зависимости, фиксированный шаг, диагностика и освобождение ресурсов |
| `src/world/` | Архипелаг, дороги, участки, маршруты, берег и опора |
| `src/simulation/` | Игрок, люди, транспорт, полиция, службы, события и контакты |
| `src/render/three/` | Сцена, камера, материалы, модели, анимации и эффекты |
| `src/render/canvas/` | Совместимый Canvas-рендерер и его проверки |
| `src/render/shared/`, `src/assets/` | Общая геометрия и ресурсы транспорта |
| `src/ui/` | HUD, карта, гараж, меню и стили |
| `src/tools/` | Средства проверки поездок |
| `src/labs/legacy/` | Исследовательские системы физики и ИИ, используемые лабораториями и CI |
| `tests/matrix/` | Проверки сочетаний поверхности, контактов, анимаций и настроек |

`createGameRuntime({environment, dependencies})` позволяет управлять временем и подменять окружение в тестах. `start()`, `step(dt)`, `render()` и `stop()` определяют жизненный цикл. Тесты города импортируют рабочий runtime напрямую.
